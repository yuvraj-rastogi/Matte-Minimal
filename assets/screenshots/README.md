# SUMIRO screenshots

Capture screenshots from the real editor after applying the corresponding SUMIRO
theme. Save them here using these names, or update the paths in the root README:

- `sumiro-cursor-oled.png`
- `sumiro-vercel-dark.png`
- `sumiro-vscode-oled.png`
- `sumiro-xcode-dark.png`

Suggested capture checklist:

1. Show the editor, tabs, sidebar, and syntax highlighting, not just a settings page.
2. Use a small, readable code example and remove private project information.
3. Keep the screenshot unaltered other than cropping or resizing for clarity.
4. Use PNG or WebP, crop out unrelated desktop clutter, and keep the images reasonably small.
5. After adding the images, uncomment the preview gallery in the root `README.md`.

You can store screenshots in this repository at no hosting cost. With a public
repository URL configured correctly in `package.json`, relative image paths can
also be rendered on the Visual Studio Marketplace README. Verify the result in
the Marketplace preview before publishing.
